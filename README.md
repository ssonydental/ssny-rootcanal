# rootcanal.ssonydental.com

Static root canal landing page for Smile Services of New York.

## Deploy with GitHub Pages
1. Create a new repo (e.g. `ssonydental/ssny-rootcanal`) and upload every file in this folder to the root (keep the `assets/` folder).
2. Settings > Pages > Source: Deploy from a branch > `main` / `/ (root)` > Save.
3. In your DNS, add a CNAME record: `rootcanal` -> `ssonydental.github.io`.
4. Settings > Pages > Custom domain: `rootcanal.ssonydental.com`, then tick Enforce HTTPS once the certificate is issued.

The `CNAME` file in this folder keeps the custom domain set across deploys.
